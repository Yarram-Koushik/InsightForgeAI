# InsightForgeAI – Phase 2 Plan

**Goal:** Turn the Phase-1 data foundation into an intelligent analysis engine so users can ask questions in natural language and receive SQL-backed answers, charts, forecasts and narrative insights.

## Sub-Phase Overview

### 2.1 DuckDB Query Engine & Queryable Workspace  ← CURRENT
**Status:** In progress  
**Deliverables:**
- Workspace holds a DuckDB connection (in-memory by default)
- Every cleaned dataset is automatically registered as a DuckDB table
- `execute_sql()` with safety guard (read-only statements only)
- `list_duckdb_tables()` + `get_table_schema()`
- New “SQL Query” tab in Streamlit UI with schema inspector + results
- Soft LIMIT protection

**Success criteria:**
- Load any CSV/Excel → clean → open SQL tab → run `SELECT …` against the table and see correct results.

### 2.2 LLM Integration + NL-to-SQL
- Wire Groq (primary) and Gemini (fallback)
- Prompt templates that include table schemas + sample rows
- Generate SQL from natural language questions
- Execute + return results + short explanation
- Error recovery / self-correction loop

### 2.3 LangGraph Multi-Agent System
Agents:
- SchemaAgent – understands semantic types & relationships
- SQLAgent – writes & validates queries
- VizAgent – chooses chart type & generates Plotly specs
- InsightAgent – writes narrative / root-cause analysis
- CriticAgent – checks for hallucinations / empty results

Orchestrator routes questions and aggregates final answer.

### 2.4 Automated Visualization
- Detect intent (trend, comparison, distribution, composition…)
- Auto-generate Plotly charts from query results
- Embed charts in the chat / dashboard view

### 2.5 Forecasting & Advanced Analytics
- Detect time-series columns
- Prophet forecasts with confidence intervals
- Basic anomaly detection
- Correlation / what-if analysis

### 2.6 Production Chat UI + Persistence + Export
- Full conversational interface (chat history)
- Evidence grounding (show the SQL / data rows used)
- Export PDF / PPTX reports
- Optional file-backed DuckDB for multi-session workspaces

## Technical Notes
- Keep everything free-tier friendly (Groq free tier is excellent for SQL generation).
- DuckDB stays the single source of truth for analytics.
- All agents receive the same schema context generated by Phase-1 semantic detection.
